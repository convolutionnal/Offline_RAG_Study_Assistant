# --- PDF Processing ---------------------------------------------------
# PyMuPDF: High-performance PDF text extraction.
# Significantly faster and more accurate than PyPDF2 for
# complex academic layouts, tables, and unicode characters.

# LangChain Community: Provides the PyMuPDFLoader wrapper that

# PyTorch: Required backend for SentenceTransformers inference.

# similarity search. No external server process needed.

# semantic chunker (punkt_tab tokenizer).

# --- Developer Experience ----------------------------------------------
# Rich: Beautiful console output — progress bars, tables,
# syntax highlighting for the pipeline_runner.
rich>=13.0.0
